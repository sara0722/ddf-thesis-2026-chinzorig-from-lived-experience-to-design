# DDF Project-Page Template

Template for the **digital project documentation** of the Master's thesis in
the M.A. Design for Digital Futures programme — Faculty of Design,
Technische Hochschule Nürnberg Georg Simon Ohm.

It produces a single-page project site in the style of academic project pages:
title, abstract, research question, approach, results with media, links, and
source code.

**All requirements — content, media formats, size limits, and how to hand
in — are defined in your official student handout(s). Follow those.**
The notes in `images/`, `videos/`, and `code/` are quick reminders, not a
substitute.
