Put your images here.

Rules (Thesis Guide, Section 9):
- JPEG or WebP for photos; PNG or SVG for UI shots and diagrams
- Max 1920 px on the long edge
- Target <= 500 KB per image (export at quality ~80, or use squoosh.app)
- Roughly 5-15 images across the whole page
- Every image needs alt text and a caption in index.html

Video files go in ../videos/ (compressed MP4, max 50 MB each -
see videos/README.txt). Also add a poster frame here (video-poster.jpg).

Expected by the template as shipped (rename in index.html if you like):
  teaser.jpg      - hero image
  approach.png    - process/system diagram
  result-1.jpg .. result-4.jpg
